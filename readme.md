# Тестовый сервер

Данный сервер предназначен для выполнения тестового задания
на позицию аналитика-разработчика.
Для его запуска необходимо установить на свой компьютер Docker.

Запуск сервера осуществляется в корне проекта командой:

```shell
    docker compose up -d
```
Описание  маршутов 
1. http://localhost:8000/companies.json - список организаций
2. http://localhost:8000/trucks.json - список белазов
